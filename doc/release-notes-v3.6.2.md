## 换台更快，更新更好找

### 体验与性能

- **直播起播调优**：HLS/FLV/TS 流的起播探测参数按直播场景收紧，切台时那段黑屏等待明显变短；点播不受影响。
- 换台预加载继续生效：下一个台提前建连起流，上下切台基本是"按一下就出来"。

### 功能变更

- **「我的」页底部新增「检查更新」按钮**：不用再进「关于」里翻了，TV 遥控少按两步。
- **「关于」页现在会显示当前版本号**，一眼就能确认自己装的是哪一版。
- **检查更新失败会说清原因**：网络超时、接口限流、仓库不可达都会直接写在弹窗里，不再是"点了没反应"。
- GitHub 接口直连不通时，会自动走加速通道再试一次，国内网络下成功率更高。

### 兼容性与注意事项

- **从旧版本升级需要先卸载再安装**（卸载会清除应用数据，建议先在「设置 → 备份」导出配置）。装好这一版之后，以后的新版本都能直接覆盖升级，不用再卸载。
- 包名未变，内置直播源与频道分组不受影响。
