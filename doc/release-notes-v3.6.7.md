# MBox 3.6.7

## 本次修复

- **修复 3.6.5 / 3.6.6 打开直播页直接闪退的问题**。原因是换台后要显示的「台号 + 台名 + 线路」信息条，代码里给它设置的是另一种容器类型的排布参数，页面一测量就报错退出。现在参数由布局文件统一管理，并把这条信息真正移到画面上方（原来它被频道列表挤到了屏幕外，即使不闪退也看不见）。

## 内容与上一版一致

- 换台时提示将要切到的频道名
- 无信号频道自动跳过，不再让你干等一轮超时后手动切台
- 加载（转圈）过程中也能上下滑换台
- 直播起播更快：起播探测从 5MB / 5 秒降到 1MB / 1 秒

## 升级方式

直接覆盖安装即可，数据不受影响（自 3.6.2 起都是同一个发布来源，可直接覆盖升级）。
